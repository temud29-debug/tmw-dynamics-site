# TMW Dynamics LLC website

A lightweight static company website prepared for Apple Developer Program enrollment, App Store support, and privacy-policy URLs.

## Pages

- `index.html` — company home page
- `contact.html` — general contact and product support
- `privacy.html` — privacy policy

## Preview locally

From this directory, run:

```powershell
node server.mjs
```

Then open `http://localhost:4173/`.

## Before publishing

The site uses relative links and can be hosted directly with GitHub Pages.
